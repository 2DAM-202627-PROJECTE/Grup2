# Sonora

**Sonora** és una aplicació de streaming de música i àudio disenyada per descobrir, organitzar i escoltar les teves cançons i podcasts preferits.

---

## Característiques

- Reproducció de àudio en alta qualitat.
- Busqueda de artistes, àlbums i cançons.
- Creación y gestión de listas de reproducción (*playlists*).
- Recomenacions personalitzades segons els teus gusts.
- Mode sense connexió per escoltar les teves descàrregues.

---

## Estat del Projecte

Aquest projecte es troba actualment en **fase de planificació i desenvolupament inicial**. La arquitectura i el stack tecnològic definitiu s'aniran actualizant en aquest document en mesura que s'aniran definint.
